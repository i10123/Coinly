# Coinly

Coinly — локальное Android-приложение для учёта личных финансов. Оно помогает вести счета, операции, накопления и базовую аналитику без регистрации, рекламы и передачи данных на сервер.

Новая установка начинается с чистого состояния: демо-счета и демонстрационные операции не создаются.

## Возможности

- Счета: карты, наличные, накопления и банковские счета.
- Доходы, расходы и переводы между своими счетами.
- Редактирование и удаление операций.
- Редактирование названия и остатка счёта.
- Общий баланс, который рассчитывается из фактических остатков на счетах.
- Категории расходов и цели накопления.
- Главный экран с последними операциями, доходами и расходами за текущий месяц.
- Аналитика: расходы по категориям, доходы и расходы за шесть месяцев, интерактивная динамика баланса.
- Валюты: BYN, RUB, USD и EUR; по умолчанию — BYN.
- Реквизиты карт: название, банк, валюта, номер и срок действия. Номер можно скопировать; CVV не сохраняется.
- Импорт и экспорт резервной копии в JSON.
- Очистка финансовых данных с двойным подтверждением.
- PIN-код из четырёх цифр и вход по биометрии после его настройки.

## Хранение и обновления

Все данные хранятся локально на устройстве. Операции, счета, категории и цели можно экспортировать в резервную копию. PIN-код и реквизиты карт в экспорт не входят.

После первой установки release-версии дальнейшие обновления сохраняют данные. Для обновления APK должна быть подписана тем же release-ключом, а номер сборки в `pubspec.yaml` должен увеличиваться, например:

```yaml
version: 0.1.2+3
```

Перед удалением приложения или очисткой данных рекомендуется сделать экспорт.

## Запуск в режиме разработки

1. Установите Flutter и Android Studio.
2. Подключите телефон с включённой USB-отладкой или запустите эмулятор.
3. В корне проекта выполните:

```powershell
flutter pub get
flutter devices
flutter run -d <идентификатор-устройства>
```

Например, для физического телефона используйте идентификатор из вывода `flutter devices`.

## Release APK

Для сборки нужен локальный release-ключ. Файлы `android/key.properties` и `android/app/coinly-release.jks` приватные: не добавляйте их в Git и никому не отправляйте.

Соберите APK:

```powershell
flutter build apk --release
Copy-Item .\build\app\outputs\flutter-apk\app-release.apk .\coinly.apk -Force
```

Готовый файл — `coinly.apk` в корне проекта. Его можно передать на Android-устройство и установить вручную. Google Play Защита может показать предупреждение для APK, которая не опубликована в Google Play.

При первом переходе с версии, запущенной через `flutter run`, на release-версию нужно экспортировать данные и удалить debug-версию: они подписаны разными ключами. Последующие release-обновления устанавливаются поверх приложения без удаления данных.

## Безопасность

- Приложение не использует аккаунты, облачную синхронизацию или сетевую отправку финансовых данных.
- PIN не хранится в открытом виде: используется хеш с индивидуальной солью.
- Чувствительные настройки и реквизиты карт сохраняются в защищённом хранилище устройства.
- Резервная копия JSON не зашифрована. Храните её в безопасном месте и не пересылайте незнакомым людям.

Coinly — личный финансовый инструмент, а не банковское приложение. Регулярно создавайте резервные копии важных данных.
