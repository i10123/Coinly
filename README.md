# Coinly

Coinly — мобильное приложение для личного учёта домашнего бюджета. Интерфейс ориентирован на русскоязычных пользователей из Беларуси: основная валюта — белорусский рубль (BYN).

Проект создаётся на Flutter и работает как локальное приложение без аккаунтов, рекламы и облачной синхронизации.

## Возможности прототипа

- Общий баланс и список счетов: карты, наличные, накопления и другие счета.
- Добавление доходов, расходов и переводов между своими счетами.
- Быстрый выбор счёта и категории при создании операции.
- Пользовательские категории расходов: добавление, переименование и удаление.
- История операций, поиск и переключение между доходами и расходами.
- Итоги доходов и расходов за календарный месяц с просмотром прошлых месяцев.
- Реквизиты карт: название, банк, валюта, номер, срок действия и CVV; номер можно быстро скопировать.
- Постоянное локальное хранение операций, счетов и категорий между запусками приложения.
- Необязательный PIN-код из 4–6 цифр: его можно установить или изменить в настройках на главном экране.
- Вход по биометрии устройства после установки PIN-кода.
- Реквизиты карт и PIN хранятся в защищённом хранилище Android (Android Keystore), отдельно от обычных данных приложения.
- Тёмный интерфейс с адаптированными экранами для Android.

## Технологии

- Dart
- Flutter

## Запуск

1. Установите Flutter и Android Studio.
2. Откройте папку проекта в Android Studio.
3. Запустите Android-эмулятор через `Tools → Device Manager`.
4. В терминале проекта выполните:

```powershell
flutter pub get
flutter run -d emulator-5554
```

Если идентификатор эмулятора отличается, сначала выполните `flutter devices` и подставьте найденный идентификатор вместо `emulator-5554`.

## Безопасность

Coinly работает локально и не отправляет данные в сеть. Операции, счета и категории сохраняются на устройстве. PIN-код не хранится в открытом виде: приложение хранит только его хеш с индивидуальной солью. Реквизиты карт сохраняются в защищённом хранилище Android, использующем ключи Android Keystore; резервное копирование данных приложения Android отключено.

Это всё ещё MVP, поэтому не используйте приложение как единственное место хранения критичных банковских данных и регулярно делайте резервные копии важных данных отдельно.
